# ADR-0092 — «Мои объявления»: компактный кластер действий (меню «⋯» + премиум-CTA)

## Status
Accepted

## Date
2026-06-19

## Context
Карточка в кабинете «Мои объявления» (`MyListings.tsx`) выкладывала все
владельческие действия (Редактировать, Продвинуть, Скрыть, Продано/Сдано,
Вернуть в продажу) полноширинными пиллами в `sm:flex-col`. Стопка из 3–4 кнопок
тянула карточку по высоте, ломала баланс «фото | текст | действия», не давала
иерархии — все кнопки одинакового веса. Брендовый красный «Продвинуть» читался
как кнопка опасности/деструктивного действия (ADR-0088 ввёл сами действия, но не
их подачу).

## Decision
Свернуть зону действий в один компактный ряд, выровненный вправо и
центрированный по вертикали:
- **Редактировать** — основное действие владельца (нейтральный ink-outline +
  иконка), всегда видно.
- **Продвинуть** — мягкий **золотой premium-акцент** на токенах VIP
  (`gold` / `gold-bg` + `Sparkles`), показывается только при `promo === 'NORMAL'`.
  Тот же визуальный язык, что у VIP-бейджа; не конкурирует красным.
- **«⋯»** — overflow-меню (готовый radix `Dropdown`) со статус-переходами
  (Скрыть / Продано|Сдано / Вернуть в продажу), у каждого пункта иконка-подсказка;
  «Вернуть в продажу» (positive) подсвечивается teal.

Изменение **чисто презентационное**: набор действий (`ownerActionsFor`),
подтверждения `window.confirm` и мутация `setMyListingStatus` не тронуты. Добавлен
i18n-ключ `account.myListings.actions.more` (aria-label кебаба) в ru/uz/en.

## Consequences
Положительно:
- Высота карточки больше не диктуется стопкой кнопок; единая опрятная форма во
  всех статусах.
- Явная иерархия: routine (Edit) → upsell (Promote, золото) → редкие статус-смены
  (в меню).
- Переиспользует существующий `Dropdown`-примитив и токены — без новых
  зависимостей и без правок бэкенда/логики.

Компромиссы:
- Статус-действия на один клик глубже (за меню) — приемлемо: они редкие, а меню —
  консистентный «дом» для смены статуса.
- Состояния с единственным действием (SOLD → только «Вернуть в продажу») тоже
  держат его в меню ради единообразия раскладки.
