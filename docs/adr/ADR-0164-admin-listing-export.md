# ADR-0164 — Экспорт списка объявлений из админки

## Status

Accepted

## Date

2026-10-03

## Context

Кнопка «Экспорт» в `/admin/listings` пришла из прототипа `apps/claudeDesign`
как заглушка: показывала тост «Экспорт в CSV» и ничего не выгружала, эндпоинта
в API не было. Заказчик попросил её либо скрыть, либо доделать — выбрано
доделать. Рядом такая же заглушка «Добавить» (создания объявления из админки
нет) — её убрали.

Нужно было решить: где собирать файл (клиент или сервер), формат, объём и кто
имеет доступ.

## Decision

1. **Сервер собирает файл.** `GET /api/v1/admin/listings/export` принимает те
   же фильтры, что и список (`ListAdminListingsQueryDto`; `page`/`limit`
   игнорируются), и использует то же условие выборки и сортировку — в файле то,
   что админ видит в таблице, но все страницы сразу. Клиентская сборка из
   постраничного списка потребовала бы десятков запросов и подписи URL обложек
   на каждую строку.
2. **Формат — `.xlsx`** (`exceljs`, уже используется импортом, ADR-0162), а не
   CSV: кириллица и числа открываются в Excel без BOM и мастера импорта, а
   типизированные ячейки не дают тексту вида `=1+1` стать формулой.
3. **Лимит — 5000 самых свежих строк**, файл собирается в памяти. Если под
   фильтр попадает больше, админка сообщает, что файл неполный.
4. **Доступ — только ADMIN**, хотя сам список доступен и MODERATOR: выгрузка
   разом отдаёт телефоны и email авторов. В UI отдельной проверки роли нет —
   `RoleGuard` пускает в админку только ADMIN.
5. **Содержимое.** Без фото (sign-on-read на тысячи строк не нужен). Даты
   пишутся со сдвигом UTC+5, чтобы Excel показывал время Ташкента. Телефон —
   аккаунта, иначе подтверждённый контактный (ADR-0151). Площадь участка
   подставляется, когда жилой площади нет.

## Consequences

- Новый эндпоинт, non-breaking; существующие контракты не тронуты.
- Выгрузка не пишется в `audit_logs`: подходящего `AuditAction` нет, а его
  добавление — миграция enum. Кандидат на доработку, если понадобится след
  «кто и когда выгружал персональные данные».
- Константа лимита продублирована в `apps/api` и `apps/web`
  (`EXPORT_MAX_ROWS`) — менять нужно в обоих местах.
- При росте базы за 5000 строк под одним фильтром потребуется потоковая
  запись или фоновая задача.
