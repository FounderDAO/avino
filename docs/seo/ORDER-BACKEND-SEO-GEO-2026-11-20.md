## Контракт для frontend

Здесь фиксируется только то, что frontend будет читать или принимать. Имена полей можно предложить другие, но тогда напишите их в отчёте до реализации.

### A. Синхронизация (frontend уже готовит endpoint в ветке `SEO`)

```
POST https://avino.uz/api/seo/sync
Authorization: Bearer <SEO_SYNC_SECRET>
Content-Type: application/json

{ "listing_ids": ["<uuid>", "..."], "agent_ids": ["<uuid>"] }
```

- Пачка до 500 id; повторные вызовы безопасны.
- Ответ `200` — `{"revalidated": N, "indexnow": [...]}`.
- `401` — неверный секрет; `400` — неверное тело.
- На `5xx` повторять с паузой.

### B. Временный признак «на повторной модерации» (если AUD-9 не готов сразу)

> 2026-11-23: AUD-9 сделан, признак остаётся запасным путём — для объявлений без сохранённой одобренной версии
> (ушли на модерацию до выпуска).

`GET /listings/:id` для объявления, которое **было опубликовано** и сейчас ждёт проверки правки, отвечает:

```
404 {"error":{"code":"UNDER_REVIEW","message":"Listing is being updated","meta":{"published_at":"<ISO>","review_started_at":"<ISO>|null"},"request_id":"…"}}
```

> 2026-11-23: реализовано в `backend/` ветки `SEO` (коммит «SEO AUD-10 + контракт B»): даты — в `error.meta`
> (фильтр ошибок теперь пропускает плоский `meta`); `review_started_at` — время последнего `OWNER_EDIT`.

- Frontend на это отвечает `503` + `Retry-After: 86400`.
- Через 7 суток с `review_started_at` frontend отвечает `404`.
- Для остальных скрытых и несуществующих объявлений — обычный `404 NOT_FOUND`.

### C. Статусы

| Случай | Ответ |
|---|---|
| Удалено | `410 {"error":{"code":"GONE",…}}` — frontend вернёт 410 |
| SOLD/RENTED | `200` с `status` (пока нет решения владельца) |

### D. Новые поля

Добавляются без поломки старых клиентов:
- `updated_at`;
- `original_language`;
- признак автоперевода;
- для фото: постоянный `url`, `width`, `height`, превью.

## Решения владельца, которые вам нужны

1. Публичный доступ к фото через свой домен (2.2).
2. SOLD/RENTED: 200 или 410 через N дней (2.5).
3. Автоперевод при публикации — стоимость провайдера (2.7).
4. Точные координаты и адреса частных объявлений в публичном API (раздел K аудита). Frontend уже убирает точные координаты из своей разметки для частных объявлений.
5. Источник границ районов и лицензия (AUD-3): OSM (ODbL — атрибуция «© OpenStreetMap contributors» и
   share-alike для производной базы) или другой.
6. AUD-9: после REJECT правки на сайте остаётся одобренная версия — подтвердить. Иначе REJECT будет снимать
   объявление, как сейчас.
