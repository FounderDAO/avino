# Avino — план работ SEO/GEO (frontend и backend)

**Дата:** 2026-11-17, обновлено 2026-11-20: аудит backend (AUD-1…18), распоряжение backend `ORDER-BACKEND-SEO-GEO-2026-11-20.md`, статус frontend.

## Как работаем

| Кто | Что делает |
|---|---|
| **Backend** | Сам решает, **как** реализовать свою часть. В этом плане — только **что** нужно frontend и почему |
| **Frontend (SEO)** | Делает свою часть под текущий и новый контракт API и пушит в ветку `SEO`. Каждый push проверен: test, lint, build, живые страницы |
| **Backend (merge, выпуск)** | Мерж `SEO` → `main` и выпуск в production |

Ветка `SEO` держится в актуальном состоянии с `main`, чтобы мерж проходил без конфликтов.

## Цель

- Каждая языковая версия (uz, ru, en) индексируется как отдельная страница со своим текстом.
- Каждое объявление, район и агент достижимы по ссылкам.
- Страницы быстрые.
- Поисковики и AI-ассистенты одинаково понимают, кто такой Avino.

## Что уже сделано во frontend (ветка `SEO`, не в production)

| Область | Сделано |
|---|---|
| Языки | Canonical на свою локаль; hreflang и `x-default`; один формат адресов без слэша |
| Заголовки | H1 и `<title>` объявления из полей объекта на языке страницы; уникальные H1, title и description лендингов поиска |
| Обход | Пагинация ссылками `?page=N`; настоящие 404 (не-UUID тоже); noindex служебных и длиннохвостых URL |
| Sitemap | Индекс и файлы, кэш на час, агенты, без потолка 5 000 и без ложного lastmod |
| Разметка | Один `@graph` на страницу; единый источник фактов `entity.ts`; стабильные картинки через `/api/og`; FAQPage; og:image и og:locale |
| GEO | `llms.txt` и `llms-full.txt`; явные группы ботов в robots; IndexNow: хелпер, файл ключа, `POST /api/indexnow` для backend; вводные абзацы с живым числом объявлений |
| Совместимость | `main` (backend-код, GTM, кластеры карты) влит в `SEO`, конфликты решены |

## Решения владельца

1. Схема человекочитаемых адресов (FE-11).
2. Публичный доступ к фото через `cdn.avino.uz` (BE-5).
3. Точные координаты и адреса частных объявлений (BE-13, FE-16).
4. Перевод при публикации — стоимость провайдера (BE-8).
5. SOLD/RENTED: 200, 410 или 301 (BE-4); индексировать ли закрытые объявления.
6. Индексировать ли `/map`. Формулировка «Национальный портал недвижимости».
7. Подтверждённые контакты для разметки и `llms.txt`. Доступы: Search Console, Bing, Яндекс.Вебмастер, аналитика.

## Как проверяем результат

- Растёт число проиндексированных страниц **в каждом языке** (uz и en тоже), а не только ru.
- `/search?tx=SALE&region_id=<Ташкент>` показывает почти все объявления города, а не 35.
- Нет страниц с оценкой «Плохо» в Core Web Vitals (мобильные).
- В JSON-LD и og:image нет адресов, которые истекают.
- На каждое изменение объявления есть отправка в IndexNow; Bing Webmaster показывает приём.
- Показы и клики растут по сравнению с замером «до» (FE-4). AI-ассистенты называют Avino и ссылаются на его страницы.
