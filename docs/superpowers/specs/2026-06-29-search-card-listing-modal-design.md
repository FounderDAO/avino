# Дизайн: модальное окно деталки по клику на карточку (Zillow-стиль)

**Дата:** 2026-06-29
**Скоуп:** `apps/client/` (публичный портал)
**Статус:** утверждён к реализации

## 1. Требование

Клиент: на странице `/search` клик по карточке объявления сейчас уводит на
отдельную страницу `/listing/[id]`. Нужно, чтобы вместо перехода открывалось
**модальное окно** с деталкой поверх выдачи (как на Zillow), при этом
сохранялась возможность открыть деталку **на отдельной странице / в новой
вкладке**.

Референс: модалка деталки Zillow (`zillow.com/homedetails/...`) — оверлей поверх
результатов поиска, URL меняется на адрес объекта, выдача остаётся под модалкой,
есть тулбар действий в шапке.

## 2. Решения (утверждены с заказчиком)

| Вопрос | Решение |
|---|---|
| Мобайл (`<1000px`) | Полноэкранный лист (`h-dvh`), не центрированное окошко |
| Выкатка | Сразу по умолчанию, **без** фиче-флага |
| «Открыть на странице» | Видимая кнопка/иконка «Открыть страницу ↗» в шапке модалки **+** нативный Cmd/Ctrl/средний клик по карточке |
| Откуда открывается | С **любой** карточки под `[locale]`-лейаутом (`/search`, главная, избранное, «похожие»), не только со `/search` — намеренно, консистентно с Zillow |

## 3. Архитектура — Intercepting + Parallel Routes

Используем нативный механизм Next.js App Router «фото-модалка» (intercepting +
parallel routes). Это каноничный способ ровно для этого UX.

**Ключевое преимущество:** при открытии модалки страница `/search` (`children`
лейаута) **не размонтируется** — меняется только слот `@modal`. Значит за
модалкой сохраняются скролл выдачи, нарисованная территория, догруженные
«Показать ещё». Клиентская модалка такого не дала бы без ручного сохранения
состояния.

### Поток навигации

| Действие | Результат |
|---|---|
| Левый клик по карточке (soft-nav на `/listing/[id]`) | Перехват → модалка поверх выдачи, URL = `/listing/[id]` |
| Cmd/Ctrl/средний клик по карточке | Нативно: полная страница в новой вкладке (карточка уже `<Link>`) |
| Кнопка «Открыть страницу ↗» в модалке | Полная standalone-страница в новой вкладке (`target="_blank"`, hard-nav → перехвата нет) |
| Обновление / прямой заход / краулер на `/listing/[id]` | Полная страница как сейчас (перехвата нет → SEO/JSON-LD не трогаем) |
| Esc / клик по фону / ✕ / кнопка «Назад» браузера | `router.back()` → модалка закрывается, возврат на `/search` |
| Клик по «похожей» карточке внутри модалки | Soft-nav → повторный перехват → контент модалки сменяется на новый объект, URL обновляется |

## 4. Файлы

### Новые

1. **`apps/client/src/app/[locale]/@modal/default.tsx`**
   Фолбэк слота: `export default function Default() { return null; }`.
   Обязателен, чтобы при рендере без перехвата (полная страница, прочие роуты)
   слот отдавал пустоту.

2. **`apps/client/src/app/[locale]/@modal/(.)listing/[id]/page.tsx`**
   Серверный компонент-перехватчик. `(.)` — `@modal` и `listing` на одном уровне
   (`[locale]`). Логика:
   - `await params` → `{ locale, id }`, `setRequestLocale(locale)`.
   - `getListingById(id, locale)`; если `null` → рендерит `<ListingModal>` с
     компактным «не найдено» (НЕ `notFound()` — чтобы не ронять слот целиком).
   - Иначе рендерит `<ListingModal listingId={id}><Detail listing={listing} embedded /></ListingModal>`.
   - **Без `<JsonLd>`** — SEO отдаёт полная страница `/listing/[id]/page.tsx`.

3. **`apps/client/src/features/detail/ListingModal.tsx`** — клиентский компонент.
   - На `radix-ui` `Dialog` (как `TourRequestModal`).
   - `open` по умолчанию `true`; `onOpenChange(false) → router.back()`
     (`useRouter` из `@/i18n/navigation`).
   - **Десктоп (`lg`)**: центрированная панель `max-w-[1100px] max-h-[92vh]`,
     свой `overflow-y-auto`, скруглённые углы, оверлей-затемнение.
   - **Мобайл (`<lg`)**: полноэкранный лист `inset-0 h-dvh`, без скруглений,
     свой скролл.
   - **Шапка-тулбар** (sticky сверху, справа): ссылка «Открыть страницу ↗»
     (`@/i18n/navigation` `Link`, `target="_blank"`, `rel="noopener"`, href =
     `/listing/[id]` с префиксом локали) + кнопка ✕ (`Dialog.Close`,
     `aria-label`).
   - `Dialog.Title` (визуально скрытый, для a11y) + тело = `children`.
   - Блокировка скролла body — штатно через Radix.

## 5. Совместимость / краевые случаи

- **next-intl + parallel routes**: слот `@modal` живёт под `[locale]`-лейаутом,
  префикс локали обрабатывается сегментом `[locale]`; перехватчик вызывает
  `setRequestLocale`. Конфликта с middleware next-intl нет.
- **Любая карточка открывает модалку** (главная/избранное/«похожие») — намеренно
  (утверждено). Обновление/новая вкладка везде дают полную страницу.
- **`PropertyCard` не меняется** — остаётся `<Link href="/listing/[id]">`;
  модификаторный клик нативно открывает полную страницу в новой вкладке.
- **SEO**: краулеры и прямые заходы идут на полную страницу с JSON-LD; модалка —
  только для soft-nav, без дублирования разметки.
- **Карта/галерея в модалке**: `DetailMap` (`dynamic ssr:false`) и `Gallery`
  монтируются при открытии диалога — контейнеры имеют фикс-высоту, проблем нет.
- **Не найден объект**: компактный «не найдено» внутри модалки + ссылка на
  полную страницу; не роняем слот через `notFound()`.

## 6. Вне скоупа

- Zillow-тулбар Save/Hide/More: Save (избранное) и Share уже есть внутри
  `Detail`; в тулбар модалки добавляем только «Открыть страницу ↗» и ✕.
- Фиче-флаг (выкатываем по умолчанию).
- Любые изменения в `apps/web/` и `apps/api/`.
