# Динамический price filter от текущей выдачи (client-only)

**Дата:** 2026-07-06
**Статус:** утверждён
**Область:** только `apps/client`

## Проблема

Слайдер цены на `/search` статичен (`$0 – $2M+`): гистограмма приходит из
`GET /search/price-distribution`, который считает распределение глобально по
всем ACTIVE-объявлениям страны и не знает про текущие фильтры/карту. При выдаче
«город Ташкент» (13 объявлений, $45k–$132k) слайдер бесполезен.

## Решение

Домен слайдера и гистограмма считаются **на клиенте из цен текущей выдачи** —
того же списка объявлений, что уже загружен для карточек (`useViewportSearch`).
Любое изменение выдачи (карта, район, фильтры) автоматически пересчитывает
фильтр. Новых запросов к API нет.

## Дизайн

### 1. Зеркало цен в Redux

По образцу зеркала territory (`SearchResults.tsx` → `setTerritory`):

- В search-слайсе появляется `resultPrices: { price: number; currency: Currency }[]`.
- `SearchResults` в `useEffect` диспатчит цены текущих items; при уходе со
  страницы — сброс (cleanup, как у territory).
- Храним **сырые пары цена+валюта**, не конвертированные числа: тоггл
  [сум|$] должен пересчитывать фильтр без обновления списка.

### 2. PriceFilter

- Убирается `useGetPriceDistributionQuery`.
- Цены из Redux конвертируются в display-валюту через существующий
  `convertPrice()` (курс ЦБУ из стора).
- Домен: `min = 0`; `max =` максимальная цена выдачи, округлённая вверх до
  «красивого» числа (аналог серверного `niceCeil`, портируется на клиент).
  Пример: max $132k → домен `$0 – $140k`.
- Выдача пуста или ещё грузится → фолбэк `$0 – $1M` (USD) /
  `0 – 12 млрд` (UZS) — текущий `FALLBACK_MAX`.
- Гистограмма: 30 равных интервалов `[0, max]`, счётчики по ценам выдачи —
  клиентский цикл. Подсветка столбцов в диапазоне не меняется.
- Подпись правого края: без «+», если ничего дороже домена нет (домен теперь
  накрывает max выдачи).

### 3. Чистка

- `apps/client/src/store/api/priceDistributionApi.ts` становится мёртвым —
  удалить вместе с использованием.
- Бэкенд-эндпоинт `/search/price-distribution` НЕ трогаем (может использоваться
  мобилкой).

## Принятые ограничения

- Список приходит страницами по 60 (`SEARCH_PAGE_SIZE`): при выдаче >60
  объявлений max считается по первой странице (сортировка промо/дата) и может
  быть занижен. Осознанный выбор в пользу простоты.
- Пока попап открыт и выдача обновилась (пан карты), домен может измениться;
  драфт пользователя не сбрасывается (эффект ре-инициализации не зависит от
  домена — существующее поведение).

## Тестирование

- Unit: клиентский `niceCeil`, расчёт бакетов, конвертация пар цена+валюта.
- Компонентные тесты PriceFilter: динамический домен из стора, фолбэк при
  пустой выдаче.
- Live-проверка на staging-каталоге: слайдер отражает реальные min/max выдачи.
